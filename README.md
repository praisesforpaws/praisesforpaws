
# Praises for Paws 🐾

A pink and charcoal-grey website for Praises for Paws, a student-led initiative focused on pet welfare.

## Mission

Make every set of paws feel loved and help pets get the basic facilities they need.

## Main goals

- Fundraising for pet medical bills and supplies
- Encouraging responsible adoption
- Promoting pet welfare and responsible pet ownership

## Pages

- Home
- Donate
- About Us
- Programs
- Volunteer
- Events
- Success Stories
- Contact

## Project structure

- `index.html` and the other HTML files contain individual pages.
- `css/style.css` contains the shared site design.
- `js/main.js` handles shared navigation, the homepage carousel, event galleries, impact counters, and demo forms.
- `images/` is for local images.

## Run locally

Open `index.html` in a browser.

## Publish

In GitHub, open Settings → Pages. Select Deploy from a branch, choose `main` and `/ (root)`, and save.

## Before publishing

- Replace example names, stories, contact details, and event information.
- Replace sample impact totals with verified numbers.
- Add official social media links and approved images.
- Connect a payment provider before accepting donations.
- Connect a form service before collecting submissions.
